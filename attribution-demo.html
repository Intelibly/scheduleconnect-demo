Testing Instructions
  1. Load Attribution Data: Click one of the campaign buttons above (e.g., "Google Ads Campaign")
  2. Verify Capture: The purple banner will appear showing captured attribution parameters
  3. Search Providers: Use the map widget below (try ZIP 75217 or any ZIP)
  4. Book Appointment: Click "Book Now" on any provider to open the booking component
  5. Verify Flow: Check browser console (F12) to see attribution data being passed to the booking iframe
  6. Backend Verification: Attribution data is automatically saved with the booking record in the database

Supported Attribution Types
  • UTM Parameters: source, medium, campaign, term, content
  • Google Ads: gclid (Google Click ID)
  • Facebook Ads: fbclid (Facebook Click ID)
  • Microsoft Ads: msclkid (Microsoft Click ID)
  • Twitter: twclid (Twitter Click ID)
  • TikTok: ttclid (TikTok Click ID)
  • LinkedIn: li_fat_id (LinkedIn First-party Ad Tracking)
