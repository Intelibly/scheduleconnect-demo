Testing Geolocation in Iframe Context

About This Test

This page demonstrates how to embed the FinderConnect map widget in an iframe while enabling geolocation functionality. For geolocation to work within an iframe, the iframe must have the allow="geolocation" attribute set.

Key Requirements for Iframe Geolocation

  • Permissions Policy: The iframe must include allow="geolocation" attribute
  • HTTPS: Geolocation requires a secure context (HTTPS) in modern browsers
  • User Permission: The browser will prompt the user to grant location access
  • Same-Origin or CORS: Cross-origin iframes need proper permissions policy

Iframe Integration Code

<!-- Iframe with geolocation permission enabled --> <iframe src="finderconnect-map.html" width="100%" height="700" allow="geolocation" style="border: none;" ></iframe>
Important: Without the allow="geolocation" attribute, the browser will block geolocation requests from the iframe content, even if the user has previously granted permission to the parent page.

Iframe Permission Comparison

Compare the behavior with and without the allow="geolocation" attribute:

With allow="geolocation"
<iframe src="finderconnect-map.html" allow="geolocation" ></iframe>
  • Geolocation requests work
  • User sees permission prompt
  • Location-based search enabled
Without allow="geolocation"
<iframe src="finderconnect-map.html" ></iframe>
  • Geolocation blocked by browser
  • No permission prompt shown
  • Falls back to manual address entry
