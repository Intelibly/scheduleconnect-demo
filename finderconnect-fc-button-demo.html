What's Being Tested
  • URL parameter extraction
  • Attribution data capture (UTM params, click IDs)
  • finderCONNECT button binding via <fc-button>
  • Provider and location identification using separate data-location-internal-id and data-provider-internal-id attributes
  • Automatic SDK handling of booking flow
  • Backend storage (staging database)
Supported Attribution Types
  • UTM Parameters: source, medium, campaign, term, content
  • Google Ads: gclid (Google Click ID)
  • Facebook Ads: fbclid (Facebook Click ID)
  • Microsoft Ads: msclkid (Microsoft Click ID)
  • Twitter: twclid (Twitter Click ID)
  • TikTok: ttclid (TikTok Click ID)
  • LinkedIn: li_fat_id (LinkedIn First-party Ad Tracking)
